# 🐾 OctoCAT Supply Chain Roadmap

A smart cat-powered supply chain management system tracking suppliers, products, orders, and deliveries end-to-end.

## 📋 Summary

| Area | Item | Type | Priority |
|------|------|------|----------|
| Data | Persistent database storage | 🚀 | high |
| Products | Inventory stock tracking | 🚀 | high |
| Orders | Order status filtering | 🚀 | medium |
| Suppliers | Supplier performance dashboard | 🚀 | medium |
| Deliveries | Delivery tracking | 🚀 | medium |
| Access | Role-based access controls | 🚀 | high |
| API | Pagination across entity lists | 🚀 | low |
| API | Automated API test coverage | 🚀 | medium |
| Data | In-memory data loss on API restart | 🐞 | high |

## 🚀 Planned Features

- 🚀 Persistent database storage — priority: high
- 🚀 Inventory stock tracking for products — priority: high
- 🚀 Order status filtering — priority: medium
- 🚀 Supplier performance dashboard — priority: medium
- 🚀 Delivery tracking for order-detail deliveries — priority: medium
- 🚀 Role-based access controls — priority: high
- 🚀 Pagination across entity lists — priority: low
